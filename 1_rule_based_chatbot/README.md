# Rule-Based Chatbot

## Project Description

This project is a simple Rule-Based Chatbot developed in Python as part of the DecodeLabs Artificial Intelligence Internship.

The chatbot interacts with users by recognizing predefined inputs and generating corresponding responses. It uses a Python dictionary to store questions and answers and conditional statements to control the conversation.

### Features
- Responds to predefined questions and greetings.
- Uses a dictionary to store predefined responses.
- Supports case-insensitive input.
- Removes unnecessary spaces from user input.
- Provides a fallback response for unrecognized questions.
- Runs continuously until the user enters `exit`.

## Technologies Used
- Python 3.12
- Visual Studio Code

## How to Run

**Step 1:** Ensure Python is installed.

**Step 2:** Open the project folder in VS Code.

**Step 3:** Open the VS Code terminal and execute:

```bash
python rule_based_chatbot.py
```

**Step 4:** Enter questions to interact with the chatbot. Type `exit` to terminate the program.
